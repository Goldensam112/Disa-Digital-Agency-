DEPLOYMENT
1. Back up the existing website first.
2. Upload the CONTENTS of this folder to your hosting document root (often public_html), keeping the assets folder and all HTML files in the same relative structure.
3. Ensure https://disadigital.online/ is the chosen canonical host. If the host redirects www/non-www, align the canonical tags and sitemap to that redirect destination.
4. Test each page, contact form, mobile menu, favicon and all links after upload. The contact form opens WhatsApp; it does not submit to a website database.
5. Submit /sitemap.xml in Google Search Console after deployment. Recheck PageSpeed Insights and Core Web Vitals; performance scores cannot be guaranteed without testing on the live host.

IMPORTANT REVIEW NOTES
- Confirm business registration details before adding any registration number or certificate claim.
- Only add genuine testimonials and verified results with client permission. This package intentionally avoids invented reviews, fake metrics and guaranteed ranking claims.
- Review current Google Play age ratings and Data safety disclosures. The Pulse Chat listing description and displayed rating may need consistency review in Play Console.
- Privacy, terms and refund pages are starter policy text, not legal advice; customize them to actual business processes before publishing.
- If you use analytics, ad scripts, or cookie-based tools later, update privacy/cookie disclosures and consent behavior as required.
