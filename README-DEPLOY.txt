DEPLOYMENT
1. Extract this ZIP on your computer. Upload the CONTENTS of the extracted folder (not the outer folder) to the ROOT of the GitHub repository, preserving the assets folder and all root-level HTML files.
2. Commit the changes to the branch selected in GitHub Pages settings (usually main; folder usually /root).
3. This build uses relative local paths (./assets/site.css, ./services.html, etc.) so assets and navigation work both on a custom domain root and on a GitHub Pages project URL under /repository-name/.
4. In repository Settings > Pages, verify the source branch/folder. If using the custom domain, verify the Custom domain field and DNS; this package does not change DNS.
5. After deployment, open the live site and hard-refresh with Ctrl+F5. Test homepage, all page links, app links, WhatsApp form, mobile menu, favicon, og-image.png and sitemap.xml.
4. The contact form prepares a WhatsApp message in the visitor's browser. It does not submit to a website database or CRM.
5. Submit https://www.disadigital.online/sitemap.xml in Google Search Console and inspect the homepage and products page.
6. Test PageSpeed Insights, mobile Core Web Vitals and structured data after deployment. This ZIP does not itself prove a live performance score, indexing, ranking or AI Overview inclusion.
